# Code of Conduct

## Expected behavior

Be respectful in issues, pull requests, and other project spaces. Disagree about the code, not the person. Assume good intent, and keep feedback specific enough that someone can act on it.

## Unacceptable behavior

Harassment, personal attacks, and sexual language or imagery are not welcome. Do not post other people's private information. Do not open a public issue for a security vulnerability.

## Reporting

For conduct problems, email [virrdhiman@gmail.com](mailto:virrdhiman@gmail.com) or use the contact on [virender.in](https://virender.in). For security reports, follow [docs/SECURITY.md](docs/SECURITY.md) and keep the details private.

## Scope

This applies to the VD Agent repository and the spaces used to discuss it. The project author decides how to respond, including closing threads or blocking further participation.
