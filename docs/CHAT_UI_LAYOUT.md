# Chat UI layout

When a file is open while the Agent panel is active, VD Agent shows chat and the
editor in a resizable split view. Drag the divider, or focus it and use the
arrow keys to adjust the split; `Home` and `End` move to the minimum and maximum
chat widths. The divider has a separator role and announces the current ratio
to assistive technology.

On narrow windows the split changes to a vertical stack so both panes remain
usable. Other panels keep their full-width layout, and the bottom terminal
continues to use the same height and toggle behavior.
